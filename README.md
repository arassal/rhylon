# rhylon

Public collaboration repo for Rhylon prototypes and supporting components.

Current scope:

- `joystick/`: standalone proof-of-concept joystick UI for a 4-motor car layout
- `joystick/ros2_ws/`: ROS 2 workspace for `/cmd_vel`, simulated base, and RViz demo
- `reference/mechanical_bom/`: mechanical and buy-list reference files

Notes:

- This repo is separate from the reference source material.
- Some interaction patterns are being reused as reference only where it makes sense.
